# SAT Math

A personal SAT Math study app with the Desmos graphing calculator built in, the way it is on the digital SAT, and an AI tutor that can see the question and your graph.

It runs entirely in the browser. Progress is saved in your own browser, and the AI tutor uses your own Gemini key, stored only in your browser. If you also use SAT Reading & Writing on the same site, the tutor can reuse the key you saved there.

## What's in it

- **Practice by skill**: all 19 SAT Math skills across Algebra, Advanced Math, Problem-Solving and Data Analysis, and Geometry and Trigonometry. Questions are generated fresh from 57 templates, so you never run out, and difficulty adjusts as you get questions right or wrong.
- **Every question explains itself**: a step-by-step solution, the fastest Desmos method (one click loads it into the calculator), and for wrong choices, the specific mistake that choice comes from.
- **Desmos Playbook**: 11 short lessons on the calculator moves that save the most time (graph both sides, sliders, regression, overlaying answer choices, and more), each with an example and a practice set.
- **Timed module**: 22 questions in 35 minutes with the same mix of topics as the real test, easier questions first, mark-for-review, and a full review afterward.
- **AI tutor** (Gemini): hints that don't give the answer away, full explanations, "show me in Desmos", and "check my graph", which sends a picture of your graph.
- **Typed answers follow Bluebook's rules**: up to 5 characters (6 with a minus sign), fractions or decimals, and non-terminating decimals must fill the box.
- Mistake review, progress by skill, backup and restore, and light and dark themes.

## How it's built

Plain HTML, CSS and JavaScript with no build step. The Desmos calculator loads from Desmos's API (the public trial key by default; paste your own in Settings), and KaTeX renders the math.

- `js/core.js`: seeded random numbers, exact fractions, formatting, and the answer-box rules
- `js/bank-*.js`: the question templates, one file per content domain
- `js/playbook.js`: the Desmos lessons
- `js/store.js`, `js/calc.js`, `js/tutor.js`, `js/app.js`: progress, the calculator, the tutor, and the screens

Every template computes its answer from the numbers it picked, and has a `check()` that verifies the answer a second way.

## Run it locally

```
node tools/serve.js
```

Then open http://localhost:8014.

## Test it

```
node tests/verify.js 1000
```

This generates 1,000 questions per template per difficulty level and checks that each answer is correct and that no wrong choice is also correct. It also checks for duplicate choices, answers that don't fit the answer box, broken math markup, and the typed-answer rules.
